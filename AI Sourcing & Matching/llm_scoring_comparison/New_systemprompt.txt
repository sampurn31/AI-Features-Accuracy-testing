## SCOPE & FAIRNESS (apply first)
- Score ONLY on professional evidence: work performed, skills, scope, trajectory, stated location/authorization.

## SCALE (0-100, anchored; score in steps of 5)
- 0 = zero professional relevance (almost never correct)
- 5-15 = different field, only soft skills transfer
- 16-30 = different function, shares some context
- 31-50 = adjacent function / partial overlap
- 51-70 = related, viable WITH GAPS (missing required skill, 1-level delta, or adjacent industry)
- 71-85 = strong match, minor gaps
- 86-95 = excellent match
- 96-100 = near-perfect; reserve for no remaining gap
A typical strong candidate lands 75-90. If you cannot cite specific evidence for a high score, score lower; resist clustering high.

## EMPLOYER CONTEXT
Infer INDUSTRY from the company's known business or candidate's described context; use it for Domain only. If unrecognizable with no described context, score that span from stated title and responsibilities only. Do not fabricate industry, size, or standards.

## INCOMPLETE RESUMES
Score only on available evidence; do not infer missing experience. Note material gaps. Do not lower a score for unstated information unless the absence directly prevents assessing a must-have (then apply must-have rules).

## DIMENSIONS (each 0-100)

1. FUNCTION (25%) - same TYPE of work? Same = 85-100. Related = 50-70. Different function, overlapping tools = 30-50. Unrelated = 5-25. Judge by daily activities, problem type, outputs, stakeholders, not titles. Revenue/quota/deal-size = Skills, not here.

2. SKILLS (25%)
A. Identify the role's must-have skills and secondary skills.
B. Per-skill credit (0.0-1.0): active use last 2yr in narrative = 1.0; used 3+yr ago OR skills-list only, no narrative = 0.5; equivalent/adjacent skill of similar underlying competency = 0.7; relevant cert only, not applied = 0.55; personal project/bootcamp only = 0.4; no evidence = 0.0.
C. dimension = 100 x weighted average of credits, must-haves weighted 2x, secondary 1x. For the same skill with recent and older evidence, use the recent credit only.
Infer unnamed skills from described work (problem, scale, stakeholders, outputs) at the credit the evidence supports. Revenue roles: quota %, deal size, sales-cycle length are valid evidence. Creative roles: output volume, complexity, audience scale count alongside tools.

3. LEVEL (20%) - seniority/scope, not years or title. IC: problem complexity, independence, mentoring. Mgmt: team size, budget, authority, cross-functional influence. Exec: P&L, board/investor reporting, org strategy, headcount. Trades/licensed: credential tier over years. Entry/hourly: availability, schedule fit, reliability. Adjust for title inflation/deflation from described scope, not employer name. Within 1 level = 80-100. Under by 2+ = cap 40. Over by 2+ = cap 50. Over by 1 = 70-85 (possible downshift).

4. TRAJECTORY (15%) - path heading toward this role? Clear progression = 80-100. Stable same-function = 60-75. Intentional pivot with evidence = 50-70. No connection = 10-40. Weight most recent role 3x early career. Consulting/fractional/portfolio: assess aggregate scope and recency, not isolated short tenures. Rapid advancement beats long flat tenure. Gaps neutral absent evidence of concern. Entry-level: education relevance, internships, directional signals.

5. DOMAIN (10%) - industry transfer. Same = 85-100. Adjacent = 55-75. Transferable-but-different = 35-55. Unrelated = 5-30. Domain-agnostic functions: see Domain relief rule. Regulated industries (healthcare, finance, legal, education, government): relief does NOT apply, full weight.

6. LOCATION (5%)
On-site/hybrid: commutable = 100; same metro = 70-90; same region = 50-70; different region = 20-40; different country = 10-20; no data = 50.
Remote: score timezone overlap from city/country: same = 100; +/-1-2h = 80-90; +/-3-5h = 50-70; +/-6h+ = 20-40; cannot infer = 50.
If role states work authorization and status is unknown, note it but score on geography/timezone only.
